> **WNK Content Skills** — Жасанды интеллект мәтіндеріндегі жаттанды клишелерді жойып, оқырман назарын бірден аударатын вирустық тақырыптар, драматургиялық сторителлинг және қарапайым түсінікті тіл қалыптастыруға арналған 5 кәсіби скилл.

---

## 📦 Жинаққа кіретін скиллдер:

| # | Скилл атауы | Қызметі |
|---|-------------|---------|
| 1 | **`anti-ai-writing`** | Мәтінді жасанды интеллект клишелерінен, бос сөздерден тазартып, тірі адам жазғандай шынайы етеді. |
| 2 | **`viral-hooks`** | Алғашқы 3 секундта оқырман назарын ұстап қалатын 4 түрлі психологиялық ілмектер дайындайды. |
| 3 | **`storytelling`** | 3 актілі драматургиялық құрылым бойынша оқиға желісін құрып, оқырманды соңына дейін ұстайды. |
| 4 | **`simplifier`** | Күрделі техникалық және IT терминдерді қарапайым өмірлік аналогиялармен түсіндіреді. |
| 5 | **`voice-dna`** | Автордың өзіндік сөйлеу мәнері мен жеке қолтаңбасын сақтай отырып контент генерациялайды. |

## 🛠️ Қалай қолдануға болады?

### 1. Claude немесе кез келген AI чатта қолдану:
Кез келген скиллдің `SKILL.md` файлын ашып, ішіндегі нұсқаулықты өз мәтініңізбен бірге чатқа жіберіңіз:
```markdown
Төмендегі WNK Content Skills ережелерін қолдана отырып, мына мәтінімді қайта өңдеп бер:

[Мәтініңіз]
```

### 2. Antigravity / Claude Code ішінде пайдалану:
Скиллдерді өз компьютеріңіздегі скиллдер папкасына қосыңыз:
```bash
git clone https://github.com/artishertekuly-bit/wnk-content-skills.git ~/.gemini/config/skills/wnk-content-skills
```
